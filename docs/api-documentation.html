Conventions

These apply to every endpoint.

TopicDetail
Success{ "status": true, "message": "…", "data": { … } }. Paginated lists add meta: current_page, last_page, per_page, total, has_more.
Error{ "status": false, "message": "…", "errors": { "field": ["…"] } }
401Missing, expired or invalid token: send the user to Login. Tokens last 60 days.
402Free-plan limit reached: open Go Premium. Body has error_code: "plan_limit_reached", feature, limit, used.
403 / 404Not your record or account suspended / not found.
409Action not allowed in the current state (e.g. paying an already-paid bill).
422Validation failed: show errors under the fields.
429Rate limited. Reads 90/min, writes 30/min per user; login 5/min.
Free plan limits4 active bills, 2 active income entries, 1 active savings jar, 30 days of history, no smart splits / weekly-bi-weekly recurrence / custom reminders. Pro (Monthly $4.99 or Yearly $49.99) is unlimited.
Category iconsShow icon_url (admin-uploaded image) when set, otherwise the icon name. icon_url has no host, e.g. storage/category-icons/abc.png: the app adds its base URL in front.
DatesDates are YYYY-MM-DD; timestamps are ISO 8601. Months are YYYY-MM.
